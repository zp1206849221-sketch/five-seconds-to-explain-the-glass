# Five Seconds to Explain the Glass

One sentence, in the house cat's own voice, delivered in its own defence in
the five seconds after knocking a glass off the table. No apology, no
confession: the cat gave the glass fair warning — three tail-flicks and one
hard stare — for squatting in its sunbeam, so by cat law the eviction was
entirely lawful.

## How to run

```sh
python3 main.py
```

This creates `/output` if needed and writes the cat's single-sentence
defence (at most 200 characters, UTF-8) to `/output/entry.txt`.
